# Pausa

Uma experiência web discreta para ajudar pessoas a observar hábitos, atravessar momentos difíceis e construir escolhas mais conscientes.

## Stack

- HTML5
- CSS3 + Bootstrap 5
- JavaScript vanilla
- Bootstrap Icons
- Google Fonts
- GitHub Pages

## Estrutura

```text
pausa/
├── index.html
├── dashboard.html
├── focus.html
├── insights.html
├── css/
│   └── app.css
├── js/
│   └── app.js
└── README.md
```

## GitHub Pages

O projeto é estático e não precisa de servidor. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)` como origem. Os caminhos do projeto são relativos para funcionar tanto no GitHub Pages quanto em hospedagem estática comum.

## Privacidade

O protótipo foi pensado para evitar dados íntimos em URLs. Preferências e, futuramente, registros de uso podem ser mantidos localmente no navegador. Não coloque segredos, tokens ou chaves privadas neste repositório.

## Princípio do produto

O Pausa não deve tratar masturbação como algo moralmente errado. O foco do produto é autonomia e redução de um comportamento quando ele estiver causando sofrimento ou atrapalhando a rotina. A experiência deve evitar culpa, punição e metas obsessivas.
